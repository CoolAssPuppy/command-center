# Archived design docs

These documents describe the original Command Center: a Safari web extension, a
native macOS app, and an open provider platform (ingest endpoint, SDK, token
broker, consent). That design was retired when the project pivoted to a single
Chrome MV3 extension on 2026-06-23.

They are kept for reference only and no longer match the code. For the current
project, see the root `README.md`. The pre-pivot code is preserved at the git
tag `archive/safari-platform-2026-06-23`.
